# Arara Vibes

App desktop separado e open source: uma caixa de chat fixa no topo da tela, acima dos outros apps, que carrega o Arara AI original (`arara-ai`) sobre um shim da API `vscode`. Nada do `arara-ai` é copiado.

Branches: desenvolva em `development`; PR para `main`, que empacota macOS, Linux e Windows.

Estado: shim da API em andamento (`src/shim`). Host Electron, empacotamento e teste real pendentes.
